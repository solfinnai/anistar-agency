# Anistar Agency

Static site for a talent agency in development across anime, manga, comics and gaming. The directory covers 16 divisions and 135 categories. It does not list individual talent, and it does not offer representation or booking.

Run `python3 gen.py` after changing `template.html`, `site_config.py`, or `taxonomy.py`. Preview locally with `python3 -m http.server 8000`. Check the public pages with `python3 -m unittest tests.test_site`.

Live site: https://anistar-agency.vercel.app. See [HANDOFF.md](HANDOFF.md) for project context.
